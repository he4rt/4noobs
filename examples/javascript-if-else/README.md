# IF/ELSE em JavaScript

## Sobre

As estruturas condicionais permitem que o programa tome decisões diferentes de acordo com determinadas condições.

## IF

```javascript
const idade = 20;

if (idade >= 18) {
  console.log("Maior de idade");
}
```

## ELSE

```javascript
const idade = 16;

if (idade >= 18) {
  console.log("Maior de idade");
} else {
  console.log("Menor de idade");
}
```

## ELSE IF

```javascript
const nota = 7;

if (nota >= 7) {
  console.log("Aprovado");
} else if (nota >= 5) {
  console.log("Recuperação");
} else {
  console.log("Reprovado");
}
```
